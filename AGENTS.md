# CodexJarvis

Local experimental coordination engine. Work on main; no worktrees or browser automation.
Run `python3 -m unittest discover -s tests -v` before committing.
Keep account ids, task ids, real event payloads and runtime state outside version control.
Never inspect private Desktop sockets/databases or install hooks to bypass a missing API.
No automatic archival, approvals, worker control or public publishing.
Tests must use synthetic events and a fake queue executable.
One explicitly authorized coordinator layer may own fresh assignments for an
explicit small worker group. Verify official project/execution binding first.
Preserve prior owners and fixed parent; no recursive scanner or extra watcher.
Capture source facts transactionally; coordinator judgment remains separate.
Relay each source fingerprint once; never infer task approval from readiness.
Cooperative reports default to record-only. Visible queue delivery requires
explicit human opt-in, a fresh activation floor and the original valid lease.
Never replay pre-activation reports or retry an uncertain claim. Keep visible
notices short, with identity/hash evidence in a private index. Do not claim a
hidden wake or install a hook as a delivery workaround. Preserve receipts,
input/final phases and sticky delivery history. No silent renewal or fleet wakeups.
